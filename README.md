## 策略摘要（20260924）

手机很少连 Wi-Fi，按中国移动 5G。稳定优先，不自动跨区跳。

- **ChatGPT**：选择组，默认奶昔香港。同区内 30 分钟测一次，延迟差 800ms 以内不换节点。
- **Grok 和 X**：选择组，默认奶昔香港。美西延迟高。不自动跳去美国。
- **Cursor**：偶尔用，默认美西，不探测。
- **官**：其余国外流量，默认奶昔香港。
- **狗狗**：只动手选，不后台测速。
- 首页选「官」，工作模式选「配置」。

## 手机更新

推送后：小飞机 → 配置「官」→ **更新**。

看一眼策略组：ChatGPT、Grok、官都是「奶昔香港」，Cursor 仍是「奶昔美国」。不用改节点订阅。
